CyberDefend 360Cybersecurity assessment and phishing simulation platform

A multi-tenant SaaS that measures an organisation's security posture and trains its people, built as two products over one backend.

  • DefendX. An adaptive questionnaire that scores an organisation's Cyber Safety Index, places it in risk tiers A to F and benchmarks it against regional, sector and national averages.
  • DefendX+. Phishing simulation campaigns with tracking and analytics, a live alert dashboard, security scanning, detection rules and resilience scoring.
  • Security. JWT auth, role-based access control, rate limiting and audit logging, plus endpoint agents and encrypted S3 backups.
  • Commercial. Tiered subscriptions with card and Mobile Money payments, invoicing, auto-renewal and trials.
  • Architecture. React 18 and TypeScript with Redux Toolkit and RTK Query on Vite, over a NestJS API on PostgreSQL (Prisma) with Redis/Bull queues, shipped in Docker.

FinWatchAnti-money-laundering detection platform

A financial crime detection platform covering the full path from transaction to analyst decision.

  • Backend. FastAPI with PostgreSQL and Alembic migrations, plus Redis-backed async workers with dead-letter retry.
  • Detection. An XGBoost model registry feeding the scoring pipeline, with Prometheus monitoring across the system.
  • Process split. The API, the ingestion worker and the retry worker run as separate processes, so each scales and restarts on its own.
  • Security. API-key authentication on every route, role-based access control and audit records for authenticated traffic.
  • Frontend. A React dashboard with alert queues, case management and evidence review.

  • PostgreSQL
  • Alembic
