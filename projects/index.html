FinWatch: AML Detection Platform

A financial crime detection platform covering the full path from transaction to analyst decision.

  • Backend FastAPI with PostgreSQL and Alembic migrations, plus Redis-backed async workers with dead-letter queue retry.
  • Detection An XGBoost model registry feeding the scoring pipeline, with Prometheus observability across the system.
  • Process split The API, the profile ingestion worker and the DLQ retry worker run as separate processes, so each scales and restarts on its own.
  • Deployment A Docker Compose stack (Postgres, Redis, migrations, API, both workers) for local work, and systemd units for the servers.
  • Security API key authentication on every /api/v1 route, role-based access control, and audit records written for authenticated traffic.
  • Frontend A React.js dashboard with alert queues, case management views and evidence review interfaces.

2025 Shipped Solo build

CyberDefend 360: Security Posture Platform

A cybersecurity assessment and monitoring platform for organisations, built as two products over one backend.

  • DefendX An adaptive questionnaire that scores an organisation's Cyber Safety Index, classifies it into risk tiers A to F, and benchmarks it against regional, sectoral and national averages, with generated reports and assessment history.
  • DefendX+ Phishing simulation campaigns, a live alert monitoring dashboard, security scanning, detection rule management and resilience scoring.
  • Commercial Tiered subscriptions with card and Mobile Money payments, invoicing, auto-renewal and trial lifecycle handling.
  • Admin and public System-wide analytics, a question bank, organisation oversight and audit logging, plus a public CSI directory searchable by sector, region and company size.
  • Security JWT auth, role-based access control, rate limiting and audit logging, plus endpoint agents and encrypted S3 backups.
  • Architecture React 18 and TypeScript with Redux Toolkit and RTK Query on Vite, over a NestJS API on PostgreSQL (Prisma) with Redis/Bull queues, shipped in Docker.

TokenLink Africa: Tokenization as a Service

A plug-in tokenization API and SDK that lets fintechs and banks in Ghana add secure payment and credential tokenization to existing systems, without standing up blockchain or compliance infrastructure in-house.

  • Architecture Microservices in NestJS, Java Spring Boot and Go, over a PostgreSQL database, with a Next.js frontend.
  • Multi-tenancy An Organization Service with role-based access control (Owner, Admin, Developer, Viewer), scoped API keys, webhooks and audit logging across the organisation and membership lifecycle.
  • Local rails Built for Mobile Money and GhIPSS integration, aligned with Bank of Ghana and SEC frameworks for payment and virtual asset service providers.
